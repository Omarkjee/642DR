# Reproducible results

The checked-in CSVs, plots, and JSON metadata were generated by
`python scripts/run_baselines.py` and `python scripts/run_experiments.py`.
The experiment metadata records the exact configuration and seeds. The
baseline script defaults to seeds 1000–1029; the final Q-learning sweep uses
held-out seeds 2000–2019. Running either script replaces its named outputs.
